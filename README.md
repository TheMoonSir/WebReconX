<h1 align="center">WebReconX</h1>

***

WebReconX is an open source tool designed to help security researchers and companies discover 
potential vulnerabilities such as IDOR, SQLi, and LFI, as well as other exposed assets that may indicate security weaknesses.

It allows security researchers to collect and analyze information about targets and report potential security issues they discover.
